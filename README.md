# Evan Foo 3D Portfolio

A standalone portfolio redesign built from scratch using the existing verified portfolio content and assets.

## Structure

- `index.html` — page content
- `css/style.css` — responsive 3D interface and animations
- `js/main.js` — canvas particles, parallax, reveal, tilt, module, and reel interactions
- `assets/images/` — project and profile images
- `assets/logo/` — identity assets
- `assets/resume/` — downloadable résumé

Open `index.html` to preview the site. The previous portfolio versions remain in their original folders.
