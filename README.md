# Evan Foo Portfolio

Static career portfolio built with HTML, CSS, and JavaScript.

## Structure

```text
career-portfolio/
|-- index.html
|-- README.md
|-- favicon.ico
|-- assets/
|   |-- images/
|   |-- logo/
|   |-- resume/
|   `-- videos/
|-- css/
|   `-- style.css
|-- js/
|   `-- main.js
`-- projects/
```

## Editing

- Main page content: `index.html`
- Page styling and mobile layout: `css/style.css`
- Carousels and interactive controls: `js/main.js`
- Portfolio screenshots and profile photo: `assets/images/`
- Brand marks: `assets/logo/`
- Downloadable resume: `assets/resume/resume.pdf`
- Future locally hosted video files: `assets/videos/`
- Future standalone case-study pages: `projects/`

## Preview

Open `index.html` in a browser. For the most reliable preview, serve this folder with a local web server.

## Deployment

Upload the complete `career-portfolio` folder to GitHub or deploy it to Vercel. Keep the folder structure unchanged so all asset links continue to work.
